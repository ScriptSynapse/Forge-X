Getting started

  1. Create a token under API tokens.
  2. Send it with every request: Authorization: Bearer fx_…
  3. Lists are paged: ?page=2&per_page=50 (at most 100), and return data, page, per_page, total, pages.
curl -H "Authorization: Bearer fx_…" {{ request.host_url.rstrip('/') }}/api/v1/cases?status=active

Version 1 is read-only. Evidence file content is never returned. Errors are JSON with status, error, message: 401 not signed in or bad token, 404 not found or not visible to you, 429 rate limit (see Retry-After).
